# GetHyre Website

Marketing/product website for GetHyre, built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Stack

- **Next.js 16** (App Router, TypeScript, `src/` directory)
- **Tailwind CSS 4**
- **ESLint**

Project scaffold only — page content, sections, and branding are being built out next.
